1-тарау. Кіріспе Теория

Бұл бөлімде нені үйренесіз?

Бұл — IV бөлімнің кіріспесі. Мұнда біз Python тілінің не екенін, оның не үшін қолданылатынын және алгоритм дегеніміз не екенін қарапайым тілде түсінеміз.

  • ✅ Python дегеніміз не екенін және ол қайда қолданылатынын білесіз;
  • ✅ Алгоритм дегеніміз не және оның қандай қасиеттері бар екенін түсінесіз;
  • ✅ Алғашқы Python программаңызды жаза аласыз;
  • ✅ Алгоритмдердің негізгі түрлерін ажырата аласыз.
💡 Қарапайым тілде: Python — компьютерге «не істеу керектігін» түсінікті тілде айтуға мүмкіндік беретін құрал. Ал алгоритм — сол «не істеу керектігін» ретімен жазып шығу жоспары.

Алгоритм дегеніміз не?

Алгоритм — белгілі бір мәселені шешу үшін орындалатын нақты, реттелген әрекеттер тізбегі. Күнделікті өмірде де алгоритм көп:

  • 🍵 Шай қайнату алгоритмі: су құй → қайнат → шай сал → құй → іш.
  • 🚪 Үйден шығу алгоритмі: киін → кілт ал → есікті аш → шық → құлыпта.
  • 📱 Телефон қоңырауы: қолданбаны аш → нөмір тер → қоңырау бас.

  • Псевдокод — адам түсінетін, бірақ нақты синтаксисі жоқ жазба

Блок-схема дегеніміз не?

Блок-схема — алгоритмді графикалық түрде бейнелеу тәсілі. Әр қадам арнайы пішінмен белгіленеді.

1. Сызықтық алгоритм — блок-схема

Сызықтық алгоритм — барлық қадамдар тізбектей орындалады
a = 5
b = 3
c = a + b
print(c)   # 8

2. Тармақталған алгоритм — блок-схема

Тармақталған алгоритм — шартқа байланысты бағыт таңдалады
san = 7
if san % 2 == 0:
    print("Жұп")
else:
    print("Тақ")

3. Циклдік алгоритм — блок-схема

Циклдік алгоритм — шарт орындалғанша қайталанады
for i in range(1, 6):
    print(i)
# 1 2 3 4 5

3-тарау. Python синтаксисі Теория

Айнымалы дегеніміз не?

Айнымалы — деректерді сақтауға арналған атаулы орын. Python-да айнымалыны жариялау үшін типін көрсету қажет емес, тек мән беру жеткілікті:

aty = "Айгүл"      # str
zhasy = 15          # int
boi = 1.65          # float
student = True      # bool

Айнымалы атауларына қойылатын талаптар

  • ✅ Әріптен немесе астыңғы сызықтан (_) басталуы керек
  • ✅ Тек әріп, сан және _ таңбаларынан тұруы керек
  • ❌ Саннан басталмауы керек
  • ❌ Python кілт сөздерін (if, for, def...) қолдануға болмайды
⚠️ Маңызды: Python-да айнымалы атаулары регистрге сезімтал — San мен san — екі бөлек айнымалы.

Түсініктемелер (комментарийлер)

san = 10  # Айнымалыға мән беру
"""
Көп жолдық түсініктеме.
"""

Шартты оператор дегеніміз не?

Шартты оператор — белгілі бір шарттың орындалуына байланысты әрекеттерді таңдауға мүмкіндік беретін құрылым.

if / elif / else — блок-схема

if / elif / else — үш нұсқалы тармақталу

if операторының жалпы құрылымы

if шарт1:
    # шарт1 дұрыс болса
elif шарт2:
    # шарт2 дұрыс болса
else:
    # ешбір шарт дұрыс болмаса

Шегініс (indentation) ережесі

Python-да шегініс — синтаксистің маңызды бөлігі. Шегініс 4 бос орын немесе 1 Tab арқылы жасалады.

# ДҰРЫС
if san > 0:
    print("Оң")    # 4 бос орын

# ҚАТЕ
if san > 0:
print("Оң")        # шегініс жоқ

5-тарау. Циклдер Теория

Цикл дегеніміз не?

Цикл — белгілі бір әрекеттер тізбегін бірнеше рет қайталауға арналған құрылым. Python-да екі негізгі цикл бар: for және while.

for циклі — блок-схема

for циклі — тізбектің әр элементі бойынша өтеді

while циклі — блок-схема

while циклі — шарт True болғанша қайталанады

for және while циклдерінің айырмашылығы

for цикліwhile циклі
Қайталау саны алдын ала белгіліҚайталау саны шартқа байланысты
Тізбек бойынша өтедіШарт True болғанша қайталанады
for i in range(5):while i < 5:

Циклді басқару операторлары

  • break — циклді толық тоқтатады, циклден шығады
  • continue — ағымдағы қадамды өткізіп жіберіп, келесі қадамға өтеді

range() функциясы

ЖазылуыНәтижесі
range(5)0,1,2,3,4
range(1, 5)1,2,3,4
range(0, 10, 2)0,2,4,6,8
range(5, 0, -1)5,4,3,2,1

for циклі

for i in range(1, 6):
    print(i)

sanlar = [10, 20, 30]
for s in sanlar:
    print(s)

while циклі

i = 1
while i <= 5:
    print(i)
    i += 1
Абайлаңыз: while шарты әрқашан True болса — цикл шексіз.

break және continue

for i in range(1, 10):
    if i == 5:
        break
    print(i)

def faktorial(n):
    if n == 0:
        return 1
    return n * faktorial(n - 1)

print(faktorial(5))   # 120

7-тарау. Тізімдер мен жолдар Теория

Деректер құрылымы дегеніміз не?

Деректер құрылымы — деректерді сақтау және өңдеу тәсілі. Python-да ең жиі қолданылатын құрылымдар: тізім (list), жол (str), кортеж (tuple), сөздік (dict), жиын (set).

Тізімді өңдеу — блок-схема

Тізімді өңдеу — қосу, сұрыптау, шығару

Тізім (list) ерекшеліктері

  • ✅ Реттелген — элементтердің реті маңызды
  • ✅ Өзгертілетін — элементтерді қосу, өшіру, өзгертуге болады
  • ✅ Индекстелген — әр элементтің нөмірі бар (0-ден басталады)

Индекстеу және кесу (slicing)

ӨрнекМағынасыМысал
a[0]Бірінші элемент[10,20,30] → 10
a[-1]Соңғы элемент[10,20,30] → 30
a[1:3]1-ден 3-ке дейін (3 кірмейді)[10,20,30,40] → [20,30]

Жиі қолданылатын жол әдістері

ӘдісҚызметіМысал
upper()Бас әріпке айналдыру"abc".upper() → "ABC"
lower()Кіші әріпке айналдыру"ABC".lower() → "abc"
split()Бөліктерге бөлу"a,b,c".split(",") → ["a","b","c"]
replace()Ауыстыру"abc".replace("a","x") → "xbc"
count()Санын санау"hello".count("l") → 2

Тізімдер

sanlar = [3, 1, 4, 1, 5]
print(sanlar[0])       # 3
print(len(sanlar))     # 5

sanlar.append(9)
sanlar.sort()
print(sanlar)          # [1, 1, 3, 4, 5, 9]
